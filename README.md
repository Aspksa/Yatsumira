# YATSUMIRA

Empty web application scaffold using **TypeScript**, **HTML5 Canvas**, **CSS**, and **Vite**.

## Windows

Install Node.js (with npm), then double-click `YATSUMIRA.bat`. Dependencies install on first launch. Vite starts and opens the browser automatically.

## Terminal

```sh
npm install
npm run dev
```

To verify the production build:

```sh
npm run build
```

The page is intentionally blank. No AI integration or interface has been added yet.
